## Протокол
- Development: результаты, известные до января 2022 (target < 2022-01).
- Validation: выпуск прогнозов с января 2022, с известной целью в присланном ряду.
- Модель для каждого горизонта выбирается по MAE development, validation не участвует.
- Это ретроспективная проверка: эти годы уже присутствовали в просмотренном отчёте Kimi.
  Называть их полностью нетронутым тестом нельзя. Дополнительная ретроспективная bootstrap-проверка сохранена в paired_loss_uncertainty.json; см. ограничения выборки.
- Общие даты выпуска для семи основных моделей внутри каждого горизонта.
  Макроэксперимент оценивается отдельно и не сокращает основную выборку.
- Rolling origins пересекаются: количество строк не равно числу независимых опытов.

## Ограничения и интерпретация

Результаты описывают конкретные периоды. Лучшая ошибка на validation не служит
основанием задним числом менять выбор по development. Основное сравнение MAE
не доказывает статистическое превосходство. Прогнозы отдельных прямых моделей могут
колебаться по горизонтам: каждый горизонт обучается отдельно. Отрицательные границы
устранены логарифмической конструкцией, произвольного ценового пола нет.

Naive/drift — ориентиры; ETS — сглаживание; Ridge/HGB — прямые модели лог-цены;
mean_reversion — сценарный возврат к геометрическому среднему 120 последних месяцев
с фиксированным периодом полураспада 12 месяцев; ensemble — равное среднее naive,
ETS, Ridge и mean_reversion. Новые методы и переход на лог-цель изменили эксперимент,
поэтому старые цифры Kimi с этими результатами не смешиваются.

Макропоказатели из диплома оставлены только в отдельном исследовательском сравнении:
единый сдвиг на месяц не доказывает доступность каждого показателя, исторические
пересмотры не учтены. Плохая метрика этой конфигурации не доказывает бесполезность
всех макропоказателей для Brent. Внешний прогноз EIA STEO не подмешивался: для
мартовского среза потребовался бы выпуск, реально доступный в тот момент.
