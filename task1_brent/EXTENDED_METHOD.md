# Расширенное сравнение Brent

## Данные и границы

Исходный ряд EIA: 467 месячных цен, май 1987 — март 2026, USD/баррель.
Он не обновлялся. Хеш исходного CSV сохранён в `outputs/extended_full/metadata.json`.
Готовая объединённая макротаблица CSV, упоминавшаяся в старом коде, в комплекте отсутствует. Сохранены 13 исходных XLSX, их фактические диапазоны и частота проверены в `outputs/extended_full/input_inventory.csv`. Месячные ряды начинаются в январе 2010 и заканчиваются январём–мартом 2026; дневные RUONIA и USD/RUB содержат даты до 16.04.2026. В кредите частному сектору есть дополнительные строки внутри одного месяца; в US CPI есть пропуск месяца. Времена публикации и исторические ревизии не установлены. Эти таблицы не подключены к новому обучению, апрельские значения не используются. Аудит можно повторить через `python -m task1_brent.input_inventory --output /tmp/input_inventory.csv` (нужен openpyxl из общих зависимостей). Поэтому новое
сравнение использует только известную историю Brent; результаты диплома по инфляции
и РСВ не переносятся на нефть. Лаг публикации внешних признаков здесь не возникает.
Точный день доступности месячной цены не моделируется: origin означает момент,
когда соответствующая месячная цена уже известна, а не первый день её месяца.

| Период целевых месяцев | Начало | Конец | Наблюдений |
|---|---|---|---:|
| Train | 1987-05 | 2014-06 | 326 |
| Validation | 2014-07 | 2020-04 | 70 |
| Test | 2020-05 | 2026-03 | 71 |

70/15/15 — деление календарного ряда, а не случайных окон. В полном режиме прогноз
выпускается раз в 3 месяца. Для каждого периода используются 17 дат выпуска, на
каждой проверяются все горизонты 1–21. Все целевые даты остаются внутри своего
периода. Последние 20 месяцев периода не становятся новыми origin, чтобы дальние
горизонты не имели другого состава наблюдений. Это уменьшает число проверок, зато
позволяет сравнивать модели и горизонты на одинаковых origin.

Пример первого validation-прогноза: вход нейросети июль 2013 — июнь 2014,
последнее известное значение июнь 2014, цели июль 2014 — март 2016.
Первый test-прогноз: вход май 2019 — апрель 2020, цели май 2020 — январь 2022.
Внешние границы не меняются. В expanding-проверке после появления новых фактов
модели могут обучаться на уже известной части текущего периода, но не на будущих
целях текущего origin. Это последовательный прогноз, не единственная модель,
навсегда обученная только на первых 70%.

Гиперпараметры ограничены заранее заданным набором. Выбор модели для каждого
горизонта — минимальная MAE validation; при равенстве имя модели. Выбор записывается
до расчёта test и после test не меняется. Предыдущий проект уже анализировал
историю test: это ретроспективная проверка, не нетронутый независимый holdout.
31 кандидат и всего 17 origin создают риск переобучения выбора на validation.
Пересекающиеся 21-месячные прогнозы зависимы; значимость различий не заявляется.

## Группы моделей

| Группа | Спецификации | Настройка |
|---|---|---|
| Baseline | naive, drift | Без подбора |
| Возврат к среднему | окна 60/120/180 мес. × half-life 6/12/24 | Все 9 вариантов в общей validation-таблице |
| Эконометрика | AR(1/3/6/12), ARIMA(1,1,0)/(0,1,1)/(1,1,1), ETS | Лог-цена, AR с константой и линейным трендом, ARIMA с drift, ETS с затухающим трендом; сезонность не навязывается |
| Классическое ML | прежние Ridge(alpha=1), HGB(depth=3,200 итераций) | Прямые модели на каждый горизонт, scaler только на доступных парах |
| Ансамбли | naive + ETS + Ridge + MR(120,12); четыре варианта с исключением одного участника | Равные веса, сравнение на validation |
| Нейросети | RNN(8), LSTM(8), CNN(8 фильтров, ядро 3), QRNN(8,tanh) | Одна архитектура каждого типа, окно 12, горизонты 1–21 |
| Распределительный ориентир | naive_quantiles | Эмпирические квантили исторических h-шаговых лог-доходностей на известной истории |

Все модели пересчитываются в каждой дате выпуска. Имена MR содержат параметры.
Неудачную сходимость ARIMA/ETS не скрываем: предупреждения сохранены в `warnings.json`.
Автоматическая подмена неудавшейся модели на naive не применяется: фатальная ошибка
останавливает эксперимент. Таблицы старого эксперимента сохранены отдельно.

## Нейросетевое обучение без утечки

Вход — 12 логарифмов цен. Цель — 21 накопленная лог-доходность от origin:
`log(price[t+h]/price[t])`. Для обучения допустимы только окна с `t+21 <= as_of`.
Дальний горизонт ограничивает общую обучающую выборку всех голов; у отдельных
Ridge-моделей коротких горизонтов доступных пар больше, что отражает их прямую схему.

Внутри текущей доступной истории последние 20% origin обучающих окон используются
для early stopping. Из внутреннего train исключаются окна, чья последняя цель
достигает первого validation-origin. Средние/стандартные отклонения входов и целей
считаются только по внутреннему train. Adam: lr=0.003, weight_decay=0.001,
clip_grad_norm=1, full batch, patience=20, максимум 160 эпох.
После выбора числа эпох модель заново обучается на всех парах, уже известных
в текущем origin, ровно это число эпох. Масштабирование повторно оценивается на
этих доступных парах. Финальное переобучение при выпуске прогноза после марта
2026 использует всю известную историю и не меняет сохранённые тестовые оценки.

RNN/LSTM/CNN усредняются по seed 11,23,37; QRNN — по 11,23,37,53,71.
Удачный seed по test не выбирается. `seed_metrics.csv` показывает разброс.
В `training_audit.json` сохраняются число пар, эпохи и фактические границы целей.
Расчёт детерминированный на CPU с одним потоком. GPU/MPS не обязательны.

## Сопоставление QRNN с дипломом

Прочитан предоставленный «ВКР_2026_Малахов_Дмитрий.pdf», разделы 2.5–2.6
(печатные страницы 24–27) и 2.9 (30–31), результаты главы 3.
В инфляционном варианте: один скрытый слой 8 tanh, 19 квантилей, Adam,
5 инициализаций, стандартизация внутри расширяющегося окна, изотоническая
коррекция. В дипломе признаки предварительно отбираются L1 и фиксируются;
для инфляции фиксированы эпохи, без ранней остановки. Для дневного РСВ
используется более крупная сеть 128/64/32 и early stopping.

Наша модель — **отдельная адаптация**, не дословное воспроизведение кода ВКР:
сохранены компактные 8 tanh, 19 квантилей 0.05:0.05:0.95 и 5 seed.
Вместо инфляционных макропризнаков — 12 лагов Brent; L1-отбор не заявляется.
Один общий скрытый слой питает 21 выходную голову по 19 квантилей; в дипломе
модели горизонтов независимы. Общая голова экономит обучение на короткой выборке.
Ранняя остановка добавлена согласно текущему запросу. В ВКР Adam lr=0.0003 и L2=0.0001; здесь заранее заданы lr=0.003 и weight_decay=0.001 для ограниченного 160 эпохами эксперимента. Это тоже отличие реализации, а не результат переноса параметров диплома. Цель — лог-доходность нефти,
а не инфляция. Pinball усредняется по стандартизованным целям всех горизонтов,
что придаёт им сопоставимый вес во время обучения.

После обратного масштабирования применяются `price_origin * exp(log_return)`.
Медиана интерпретируется как медианный прогноз; поправка на среднее логнормального
распределения не добавляется. Пересечения измеряются до коррекции. PAVA/isotonic
проецирует квантили каждого seed и горизонта на неубывающую последовательность,
затем прогнозы усредняются. Коррекция не использует будущие значения и не гарантирует
90% фактического покрытия. Она может объединять соседние квантильные уровни.

Метрики в исходных USD/баррель: MAE/RMSE медианы, средний pinball по 19 квантилям,
покрытие и ширина q05–q95, interval score (Winkler, alpha=.1).
`crps_central_approx = 2 * trapz(pinball, tau)` по [0.05,0.95] — только центральная
часть приближения CRPS; хвосты вне сетки не оценены. Это не полный CRPS и не
численное воспроизведение метрики диплома. Сравнение проводится с эмпирическим
распределительным ориентиром на той же сетке. Данные test не калибруют интервалы.

## Воспроизведение

Из корня проекта, в `conda activate sber` либо активированном `.venv`:

```bash
python -m pip install -r task1_brent/requirements-neural.txt
python -m task1_brent.extended_experiment --mode fast --neural --output task1_brent/outputs/my_fast
python -m task1_brent.extended_experiment --mode full --neural --output task1_brent/outputs/my_full
```

`fast`: один seed, максимум 20 эпох, шаг 12 месяцев — проверка работоспособности,
не основание для итоговых выводов. `full`: описанный выше ограниченный эксперимент.
Без `--neural` PyTorch не импортируется и базовый эксперимент работает без него.
Для повторного запуска выбери новое имя выходной папки: готовые расчёты не затираются.
Проверенная версия и фактическое время текущего запуска — `metadata.json`.
Поддержка macOS-пакета PyTorch зависит от версии macOS/Python; на самом M1 прогон
не выполнялся. При проблеме установки базовые модели остаются доступны.

Основные файлы: `split.csv`, `selection.json`, `predictions.csv`, `metrics.csv`,
`seed_metrics.csv`, `selected_forecast.csv`, `qrnn_forecast.csv`, два PNG и `RESULTS.md`.
