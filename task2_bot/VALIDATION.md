# Проверки RAG — 07.10.2026

Полный набор проекта после исправлений: 119 passed, 5 subtests passed (Linux, Python 3.12.14). API, сессии, цитаты, изоляция пользователей и новая проверка смысла протестированы офлайн с моками. Реальная надёжность смысловой проверки пока не измерена.

PDF: 236/200/43 страницы; хеши PDF, фрагментов и векторов совпали с метаданными. Индекс включён в комплект, веса E5 — нет.

Сохранённые dev-результаты (17 оцениваемых вопросов, неизменные 1136 фрагментов, top-6) проверены пересчётом попаданий и рангов:
- hybrid + ручной перевод + scope + BM25 weight 1.0: 14/17, MRR 0.6098;
- semantic без перевода: 10/17, MRR 0.2304;
- hybrid/1.0 без перевода: 7/17, MRR 0.1833.

Независимо запущен BM25 dev с ручным переводом: 13/17, MRR 0.5049. BM25 test без перевода: 5/12, MRR 0.2569; три из 15 вопросов исключены правилами retrieval-оценки. Это диагностический лексический режим, не измерение качества рабочего hybrid-бота. Test больше нельзя называть полностью непросмотренным после этого аудита.

Пересчёт E5/hybrid в среде аудита не выполнен: sentence_transformers и веса E5 отсутствовали. requirements-semantic.txt предоставляет необходимые зависимости; первая загрузка требует сети. Ручной английский перевод не измеряет качество API-переводчика.

Пользователь ранее показал отдельные успешные ответы BardBorn-бота на Mac. Это не независимая test-оценка и не проверка официального DeepSeek. В этом проходе платных вызовов и запуска Telegram не было. Живой DeepSeek, переводчик, нагрузка, prompt-injection и faithfulness всей системы требуют отдельного измерения.


## Экспериментальная доработка поиска

Добавлены переключаемый локальный CrossEncoder и проверка соответствия ответа
вопросу в существующем проверочном запросе. Проверены подмена модели тестовым
объектом, порядок выдачи, сохранение источников, межъязыковые пары, fallback,
ограничение повторов после сбоя и строгая схема результата проверки.

Измерение `outputs/rerank_candidate_diagnostic.json`: BM25/manual/dev,
top-6 13/17, top-24 17/17; полное покрытие evidence-групп 10/17 и 15/17.
Это измерение первичного поиска. Реальные веса CrossEncoder в этой среде не
загружались; качество и задержка reranker не измерены. Платный генератор и новая
проверка соответствия вопросу проверены только моками. Новые функции выключены
по умолчанию до локального сравнения. Подробные команды в README.
