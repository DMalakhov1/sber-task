полностью совпавших с каноническим снимком. Генерация и потребление полные;
720 значений ИБР Востока в ответах API равны null. Код завершения 3 ожидаем.

Проверены все 23 112 заполненных ячеек против независимого пересчёта формул
в табличном движке. Формулы не дали ошибок. Изменение C5 листа ИБР на +100
увеличило K5 с 988.1267492850437 до 997.3809831148743; исходное значение
затем восстановлено. Все три листа визуально просмотрены.

Месячные суммы: генерация **84 007 301 МВт·ч**, потребление **83 373 540 МВт·ч**.
ИБР всех семи ОЭС пуст. Частичное среднее по опубликованным ценам с весом
потребления: **2038.07763863 руб./МВт·ч**, простое среднее **2028.95862535**,
4320 опубликованных пар, покрытие веса **95.71099776%**. Это отдельный
описательный расчёт с аналитическим допущением о весе, не официальный общий ИБР.

Сохранены фильтры A4:J724 / A4:N724, закрепление C5, печатные диапазоны,
комментарии происхождения и объяснения пропусков. Экспорт проверочного движка
не сохранял автофильтр и параметры печати: в финальный исходный OOXML перенесены
только пересчитанные кэши формул, остальные элементы сохранены. Контрольные суммы
Excel обновлены в обоих JSON-отчётах. Программный экспорт по-прежнему воспроизводит
те же значения через проверенные расчёты Python; байтовое равенство XLSX не требуется.

Новые проверки: совпадающая маска цены и веса, исходные пары при месячной
агрегации, нулевой/неизвестный вес, отрицательная цена, различение пропуска строки
и null-цены, формулы/кэши, запасная публикация без hard links и откат при ошибке.
Проверки выполняются без сети. Новый запрос к API в этой доработке не выполнялся.
