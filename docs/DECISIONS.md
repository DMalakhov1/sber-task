# Решения и ограничения

1. Один проект с тремя независимыми задачами. Проверенное окружение — Python 3.12.14; семантический стек бота устанавливается отдельно.
2. Brent: месячный spot EIA, срез пользователя до марта 2026 без обновления. Март 103,13 сверён 07.10.2026: https://www.eia.gov/dnav/pet/hist/LeafHandler.ashx?n=PET&s=RBRTE&f=M . Прогноз — исторический эксперимент; дата первоначальной загрузки неизвестна. Макроэксперимент не входит в финальный выбор, задержка публикации один месяц не подтверждена.
3. DeepSeek: https://api.deepseek.com, deepseek-flash. Переменные OPENAI_BASE_URL и OPENAI_MODEL обозначают общий совместимый протокол. BardBorn включается только явно. Документация: https://api-docs.deepseek.com/ . GET /models проверяет доступность модели для введённого пользователем ключа.
4. RAG: проверки цитат доказывают происхождение выдержек. Дополнительная модельная проверка смысла может ошибаться; её качество требует живой оценки. Пользовательский ключ не включается в промпт. По умолчанию до трёх вызовов с переводом и проверкой смысла, ещё один только при включённом исправлении цитат.
5. Excel: подтверждённый сохранёнными ответами API-контракт описан в SITE_RECON.md. Время Europe/Moscow, часы 0–23, энергия МВт·ч. Предыдущий месяц выбирается автоматически.
6. ИБР: вес — фактическое потребление, явно обозначенное аналитическое допущение. Пропуск цены/веса оставляет затронутый итог пустым. Официальную методику нужно уточнить. 720 null Востока в источнике не заменяются нулями или чужими ценами.
7. ВСЕГО — ровно семь заданных систем. Допустимые Excel-имена заменяют запрещённые * и /; исходные названия сохранены в A1.
8. TLS-обход — только явный --insecure-br для фиксированного хоста без редиректов. Задержка публикации факта неизвестна; при запуске по расписанию код 3 требует проверки отчёта качества.
9. Публикация Excel/отчётов использует hard links и откат при обычной ошибке. Требуется поддерживающая их файловая система; набор со снимком не является единой атомарной транзакцией.


## Уточнение по Excel 07.10.2026

- Полный охват семи ОЭС и частичный охват опубликованных цен — разные показатели,
  показаны раздельно. Пропуски Востока не объявляются нормативно неприменимыми:
  СО ЕЭС подтверждает включение ОЭС Востока во вторую ценовую зону с 2025 года.
- Простое среднее добавлено как альтернативная описательная сводка. Рабочий вес
  по потреблению остаётся явно выбранным допущением, менять его молча нельзя.
- Энергия имеет собственный статус полноты. Отсутствие цены не делает фактическую
  генерацию/потребление отсутствующими.
- В сдаваемом outputs — один фактический Excel. Рабочие backup и синтетика могут
  генерироваться локально, но не смешиваются с результатом для проверяющего.
