# Задание 3: почасовые данные СБР → Excel

Итог для сдачи: `outputs/electricity_2026-09.xlsx`. Ровно три листа, 720 часов
сентября 2026 и семь ОЭС. Генерация и потребление содержат все 5040 значений каждого
показателя. Для Востока отсутствуют 720 цен ИБР в сохранённом ответе API.

## Что находится в книге

- Генерация и потребление: исходные почасовые значения, сумма семи ОЭС, месячные
  суммы. Статус полноты относится именно к показателю текущего листа.
- ИБР, C:I: опубликованные цены по семи ОЭС, без подмены пропусков нулями.
- ИБР, J: взвешенное среднее **всех семи ОЭС**; при отсутствующей цене или весе
  итог пуст. Этот показатель по сентябрю не может быть рассчитан полностью.
- ИБР, K: отдельное взвешенное среднее **только по опубликованным ценам** и известным
  весам. Это другой охват, а не восстановленный общий ИБР.
- ИБР, L: простое среднее опубликованных цен как альтернативный описательный
  показатель. За месяц считается по исходным парам час × ОЭС.
- ИБР, M: число опубликованных цен (за час — число ОЭС, за месяц — число пар).
- ИБР, N: доля веса пар с опубликованной ценой в весе всех пар; если общий вес
  неизвестен или равен нулю, показатель пуст.

Вес — фактическое потребление, **аналитическое допущение**, не официальная методика.
Формула: `Σ(цена × потребление) / Σ(потребление)`. Во взвешенном частичном расчёте
числитель и знаменатель используют одну маску пар с известными ценой и весом.
Месячный итог рассчитывается из исходных пар, не из средних по часам или ОЭС.
Нулевой знаменатель не превращается в нулевую цену. Отрицательная цена допустима.

Итоги записаны настоящими формулами Excel (`SUM`, `SUMPRODUCT`, `COUNT`, `AVERAGE`)
с сохранёнными числовыми результатами для просмотра до открытия в Excel.
После изменения входной ячейки Excel пересчитывает формулы. Книга — снимок источника:
его комментарии, статусы и SHA-256 относятся к моменту выгрузки, а не ручным правкам.
Строка месячных итогов исключена из фильтра, заголовки и дата закреплены.

## Почему не снята отметка неполноты ИБР Востока

СО ЕЭС подтверждает переход ОЭС Востока во вторую ценовую зону с **01.01.2025**, а
ежечасные расчёты планов БР — с **01.04.2025**. Поэтому поле старого справочника
`unPriceTerritories` не доказывает, что в сентябре 2026 показатель неприменим.
Доказан только факт `AVERAGE_PRICE=null` в сохранённых ответах. Причина его
отсутствия в этом публичном API пока не установлена. В книге не утверждается,
что цена отсутствует «по природе». Источники и контракт — `../docs/SITE_RECON.md`.

## Воспроизведение из сохранённого снимка

Все команды из корня `sber-analyst-test`, в активированном окружении:

```bash
python -m pip install -r task3_excel/requirements.txt
python -m task3_excel.export_excel --month 2026-09 --input task3_excel/data/processed/2026-09.json --weight consumption_mwh --allow-partial --output task3_excel/outputs/rebuilt_2026-09.xlsx
```

Ожидается 5040/5040 строк и 720 пропусков ИБР. **Код завершения 3 ожидаем**:
файл создан, но не все цены опубликованы. 0 — полный результат, 2 — ошибка.
Без `--allow-partial` неполный отчёт не выпускается.

Восстановление снимка и Excel из 31 сохранённого ответа, без сети:

```bash
python -m task3_excel.source_http --month 2026-09 --cache task3_excel/data/raw/2026-09 --weight consumption_mwh --allow-partial --snapshot task3_excel/data/processed/rebuilt_2026-09.json --output task3_excel/outputs/from_raw_2026-09.xlsx
```

## Новая загрузка и повторные запуски

```bash
python -m task3_excel.source_http --weight consumption_mwh --allow-partial --refresh --insecure-br --snapshot task3_excel/data/processed/new_snapshot.json --output task3_excel/outputs/new_report.xlsx
```

Без `--month` выбирается предыдущий календарный месяц по Москве. Флаг
`--insecure-br` нужен только при проблеме сертификата: он ограничен одним хостом,
редиректы запрещены. При доверенной цепочке исключите этот флаг.

По умолчанию существующий файл не перезаписывается. Для повторяемого ежемесячного
запуска можно явно задать `--overwrite`: прежний снимок и набор Excel/JSON сохраняются
как backup. В комплекте для сдачи такие рабочие копии не включены.
Для планировщика используйте абсолютные пути к Python и проекту; код 3 обрабатывайте
как предупреждение о качестве, а не сетевую ошибку. Расписание на компьютере не
устанавливается автоматически. Повторите загрузку при задержке публикации источника.

Публикация по возможности использует hard links. Если файловая система их не
поддерживает, применяется эксклюзивное копирование без перезаписи чужого файла.
Этот запасной путь не атомарен для читателя; сверяйте SHA-256 из metadata/quality.
Набор Excel и двух JSON не является единой транзакцией при аварийном завершении.

## Состав и проверки

- `data/raw/2026-09/`: один сохранённый комплект из 31 ответа и их метаданных;
- `data/processed/2026-09.json`: один нормализованный снимок;
- `outputs/electricity_2026-09.xlsx` и два сопроводительных JSON: один итог;
- `demo.py`: генератор синтетического примера по отдельному запросу, не фактический результат.

```bash
python -m pytest -q tests/test_excel.py tests/test_calendar.py tests/test_source_http.py tests/test_excel_upgrade.py
```

Флаги `intervals_complete`, `volumes_complete`, `prices_complete` в отчёте качества
различают незагруженные интервалы, пропуски объёмов и недоступные цены. Список
`unpublished_prices` содержит только строки, которые получены от источника.
Визуальная сверка с графиком сайта остаётся открытой; сверка JSON → снимок → Excel
и локальный пересчёт формул описаны в `../docs/EXCEL_UPGRADE_VALIDATION.md`.

## Быстрый маршрут для VS Code

1. Открой именно папку `sber-analyst-test` (в ней видны `task1_brent`, `task2_bot`, `task3_excel`).
2. Открой встроенный терминал и выполни `conda activate sber`.
3. Установи зависимости: `python -m pip install -r task3_excel/requirements.txt`.
4. Для просмотра готового результата на Mac: `open task3_excel/outputs/electricity_2026-09.xlsx`.
5. Для проверки алгоритма выполни одну из команд воспроизведения выше. Нужные пути уже указаны в команде.

| Команда/этап | Вход | Выход | Ожидаемый результат |
|---|---|---|---|
| `python -m task3_excel.source_http … --refresh` | Публичный API, выбранный месяц | `data/raw/<месяц>/` (при повторе вложенный refresh-каталог), путь `--snapshot`, путь `--output` и JSON рядом | Новые ответы → снимок → книга |
| `python -m task3_excel.source_http … --cache task3_excel/data/raw/2026-09` без `--refresh` | Сохранённые 31 ответ и метаданные | `--snapshot` и `--output` | Работа без сети; 5040/5040 строк; код 3 из-за 720 null-цен |
| `python -m task3_excel.export_excel … --input …` | Нормализованный JSON | `--output`, `.metadata.json`, `.quality.json` с тем же именем | Валидация и книга без повторной загрузки |
| `open task3_excel/outputs/electricity_2026-09.xlsx` | Готовая книга | Окно Excel/Numbers | Три листа, 720 часов и месячная строка |
| `python -m pytest -q tests/test_excel.py tests/test_calendar.py tests/test_source_http.py tests/test_excel_upgrade.py` | Код, сохранённые данные и тестовые примеры | Результат в терминале | Офлайн-проверки, без новых API-запросов |

Многоточие в таблице означает параметры из полных команд выше; его не нужно
копировать в терминал. В `.metadata.json` — источник, методика и контрольная сумма;
в `.quality.json` — полнота, перечень пропусков и охват частичного расчёта.
Пути относительны к корню проекта. Ключ DeepSeek/OpenAI для Excel не нужен.
